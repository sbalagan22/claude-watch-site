Icon, animation & behaviour spec — v2

Menu bar status system

The app has one job in the menu bar: answer “is it working?” without being asked. Everything below serves that, and nothing else. The glyph carries the app's identity through silhouette alone — the four-point gem inside its tilted orbit — because a macOS template image gets flattened to solid black on transparent and inverted by the system. No gradient, gloss or 3D depth survives that, so none is used. Colour appears only in the three states that are asking for the user's attention.

All five states at true size (22pt in a 36pt canvas), light bar and dark bar, template inversion live. The two shapes on the right stand in for neighbouring system items.
01

The glyph

Two forms, drawn in three layers. The gem is a single closed path with concave curved flanks — it reads as a polished four-point crystal rather than a star because the waist of each spike pulls in toward the centre. The orbit is one tilted ellipse, split into a back half and a front half so the gem can sit between them; that overlap is the only depth cue available in flat black, and it is enough. Everything lives on a 36pt canvas with the artwork occupying 8–28, leaving the margin macOS expects around a menu bar item.

Why it survives 16pt: the gem is a solid mass, not an outline, so it never fills in; the orbit crosses it at a tilt, so the two forms stay separable even when each is barely two pixels thick. The 1.3pt arc weight is the floor — thinner and the ring dissolves on a non-Retina display, heavier and the glyph out-shouts the system icons beside it.

02

Working — precession

The orbit does not slide around itself — it tips. Only the ellipse's vertical radius animates, from 5 down through 0.9 and back, which reads as the whole ring rotating in space through edge-on. The gem meanwhile turns a slow quarter over eight seconds and, because it is fourfold symmetric, arrives exactly where it started: the loop closes with no restart to catch.

Two details do the work. The stroke thickens from 1.7 to 2.5 as the ring approaches edge-on, which is what a real ring of constant thickness does when you foreshorten it — it also keeps the silhouette from thinning to nothing at the halfway point. And the ry curve is ease-in-out rather than linear, so the ring lingers at its open extremes and passes quickly through the flat, which is where a linear version looks mechanical.

It is two interpolated numbers and one rotation — cheap to reimplement, cheap to run, and calm enough to sit in your peripheral vision for an hour. Nothing travels across the screen, so the eye is never pulled sideways into it.

frame rate 12fps — steps(24) ring, steps(96) gem
timing ease-in-out (ry, stroke) · linear (rotation)
ring 0% ry 5.0 stroke 1.7 50% ry 0.9 stroke 2.5 100% ry 5.0 stroke 1.7 gem 0% rotate 0° 100% rotate 90° (loop-invariant) rx 11.5 fixed · tilt −20° fixed gem drawn above the ring at all times

03

Five states, and when each one shows

The menu bar shows one state at a time even when several sessions are running, so the states are ranked. Highest rank present wins: needs you → failed → working → done → idle. Anything that is asking for a human beats anything that is merely reporting, and reporting beats silence. The panel is where per-session truth lives; the glyph is a summary.

Idle template

Solid black at full alpha, no motion. This is the resting pose and the shape everything else is a deviation from, so it has to be the quietest thing in the bar — the front arc is thinned to 1.3 specifically so total ink lands under a typical system glyph.

shows when app launched, no session running, nothing unacknowledged
entered from done / failed once the panel has been opened, or after auto-clear
leaves on first token or tool call from any session
Working template

Precession, described above. It starts at ry 5 — the idle ring's exact geometry — so the transition into working is the animation simply beginning, with nothing to cross-fade. Still monochrome: a user glancing up learns “busy” from movement, not from colour, which leaves colour free to mean “your turn”.

shows when ≥1 session actively generating or running a tool
enter immediate, phase starts at 0% · no fade
debounce hold ≥800ms before leaving, so bursty tool calls don't flicker
leaves on last active session finishing, blocking, or failing
Done non-template

The payoff. On arrival the gem overshoots to 1.20 and settles at 1.00 while a ring blooms outward from behind it and vanishes — one gesture, 900ms, then complete stillness in #D97757. The overshoot is what makes it feel like an event rather than a colour swap; the stillness afterwards is what makes it safe to leave up, because a colour that stays put stops being urgent within seconds.

shows when a session finished successfully and the user has not looked yet
bloom once, 900ms · gem .86 → 1.20 @360ms → .97 → 1.00 · halo r11 scale .55→1.55 alpha .85→0
then static orange, indefinitely
clears on panel opened, or a new session starting (working outranks done)
preview note looped at 6s here; ships as one-shot
Needs you non-template

Same orange as done, deliberately — inventing a second alert colour would make the palette ambiguous. These two are told apart by behaviour: done happened once and went still; needs-you keeps pinging outward every 3.2 seconds and will not stop until you deal with it. Motion outranks hue for peripheral detection, so this is also the state most likely to catch you mid-task.

shows when a session is blocked on a permission prompt or a question
ping 3.2s loop, two rings offset 1.6s · scale .5→1.5, alpha .8→0, ease-out
core gem breathes 1.00↔1.05 in phase, so the glyph itself never goes flat
clears on the prompt being answered — not on the panel opening
Failed non-template

Muted red, fully static, and the orbit is broken: the front arc is dashed open so the ring no longer closes. That break is the point — a user who cannot separate #C2564A from #D97757 still sees a severed silhouette. Static because a failure is finished; animating it would imply something is still happening.

shows when a session exited non-zero or crashed, unacknowledged
geometry front arc dasharray 26 22 26 on pathLength 100
colour #C2564A · no animation, ever
clears on panel opened · outranked only by needs-you
04

Spinner style — two alternates

Settings offers three spinner styles. Precession is the default; these two exist because tolerance for peripheral motion varies a lot between people, and the setting is cheaper than losing a user who finds any movement distracting. All three share the same geometry, so switching never changes the glyph's footprint in the bar.

iQuiet

Same tipping motion, stripped to the minimum that still registers: the gem collapses to a 1.9pt core dot, the orbit becomes a hairline at 55% alpha, and the period stretches to six seconds. At a glance it looks like a static dot with a ring; only sustained attention reveals it moving. For people who want to know without being told.

period 6.000s · 12fps, steps(36)
ry 5.0 → 1.1 → 5.0 · stroke .9 @alpha .55 constant
core circle r1.9 at 18,18 · gem does not rotate
Reduce Motion: ry 2.4,
stroke 1.1 @alpha .70
iiPip

The opposite trade: figure and ground swap, so the gem becomes a hollow outline and a single solid disc travels the orbit. Highest legibility of the three at 16pt, because a moving solid disc is the most robust form there is — and it eases at the left and right extremes, where a real orbiting body appears to slow. For people who want unambiguous progress.

period 7.000s · 12fps, steps(10) per interval
pip r2.3 on offset-path = full ellipse
offset-distance 0 → 7 → 25 → 43 → 50 → 57 → 75 → 93 → 100%
(sine distribution: slow at both extremes)
gem outline stroke 1.5, joins round

low-right, clearly off-centre
05

Panel — dots, icons, empty state

The panel is the detail view: one row per session, a state dot on the left, an action icon on the right. Here every session's state is visible at once, so the dots must separate from each other rather than from a neutral ground — and they must do it without colour, since roughly one in twelve men cannot reliably split orange from red. Each state therefore gets its own form: hollow, dashed, solid-round, solid-angular, struck. Desaturate the whole column and nothing is lost.

The empty state uses the gem at 1.8× in outline only, with one accent pip resting at the orbit's lowest point — the orbit is parked, not broken, which is the difference between “nothing to do” and “something went wrong”. It is deliberately small and low-contrast: an empty panel is the normal state of a monitoring tool, not a failure, so it neither apologises nor fills the space with encouragement.

06

Implementation notes

RENDERING
· every glyph is one 36×36 vector, no rasters
· idle, working and both spinner alternates ship as
  template images — alpha is uniform per shape,
  never interpolated across pixels
· done, needs-you and failed ship non-template,
  tinted at draw time from one accent constant
· 22pt artwork in a 36pt canvas keeps macOS from
  clipping or re-padding the item
TIMING & POWER
· one shared 12fps tick drives everything
· frame index = floor(t × 12) mod (duration × 12)
· every loop is period-closed: last keyframe == first
· working: 4s ring ÷ 8s gem — least common multiple
  8s, so the pair repeats exactly
· suspend the tick when the menu bar is hidden or
  the display sleeps; resume at phase 0
ACCESSIBILITY
· Reduce Motion swaps each animated state for its
  static frame — never just pauses at phase 0,
  which would look identical to idle
· no state depends on colour alone: done/needs-you
  differ by motion, failed by broken geometry
· panel dots carry five distinct forms
· every state needs a VoiceOver label; the glyph is
  one control, not five images
